## 🔑 최종 확정 컴포넌트: 서사적 아크 완성 Paywall (Arc Completion Paywall)
**목표:** 단순 결제(Payment)를 넘어 '개인 서사 자산의 완결'이라는 감성적 경험을 제공하여 구매 전환율 극대화.
**핵심 가치 전달:** 사용자가 현재 가진 자산(Free Arc)과 완성되어야 할 잠재적 자산(Premium Arc) 사이의 **Gap (서사적 결핍)**을 시각적으로 체험하게 만든다.

### 📐 컴포넌트 구조 및 플로우 정의
| 섹션 | 명칭 | 역할/메시지 전략 | 필수 요소 |
| :--- | :--- | :--- | :--- |
| **[Step 1] Gap 진단** | **서사적 불완전성 시각화 (The Void)** | 사용자에게 현재의 이름 자산이 '미완성' 상태임을 감성적으로 각인시킨다. (Deficit Trigger) | 1. 낮은 'Completion Score' 표시. 2. 아크(Arc)가 끊긴 지점/블러 처리된 요소 시각화. 3. "무언가 중요한 연결고리가 빠져 있습니다." 문구 배치. |
| **[Step 2] 가치 제안** | **잠재적 자산 제시 (The Promise)** | 유료 결제가 단순히 '정보'를 사는 것이 아니라, '자신이 되어갈 미래의 서사'에 투자하는 것임을 강조한다. | 1. Unlock 가능한 프리미엄 모듈 목록 (Ex: 심층 배경 스토리, 역사적 기원). 2. Mockup 구매 전/후 비교 시각 자료 배치. 3. 결제액보다 '가치(Value)'에 초점을 맞춘 카피라이팅. |
| **[Step 3] 전환 유도** | **완성 버튼 (The Catalyst)** | 결제를 물리적인 행위로 인식시키지 않도록, 마치 퍼즐 조각을 맞춰넣는 듯한 느낌의 CTA를 설계한다. | 1. '서사 업데이트하기' 또는 '나의 아크 완성하기' 문구 사용. 2. 명확한 가격/플랜 제시 (A/B 테스트 용이). |

### ✨ UI 가이드라인 및 Mockup 컴포넌트 상세 정의

#### 💡 버전 A: 미니멀리즘 (Minimal, High-Tech)
*   **감성:** 데이터 기반의 과학적 발견, 정교함.
*   **톤앤매너:** 네온 시안(#00FFFF), 블랙, 화이트. 최소한의 움직임으로 최대의 임팩트.
*   **폰트:** Inter (San-serif, 가독성 최우선).
*   **Gap 표현:** 블러 처리된 데이터 영역(Data Blur)과 'Missing Link'를 나타내는 점선 아크 사용.

| 요소 | 상세 디자인 규칙 | 개발 참고 사항 |
| :--- | :--- | :--- |
| **배경** | 딥 블랙(#0A0A14) 그라데이션 (미세한 노이즈 효과 추가). | 배경에 미묘하게 흐르는 데이터 스트림 애니메이션(Low Opacity Particle System) 적용. |
| **Gap 표시** | 끊어진 아크는 네온 시안의 점선(`dashed-line`, 2px)으로 표현하고, 그 지점에 "UNKNOWN"이라는 깜빡이는 워터마크 삽입. | `[Component: ArcSegment]` 상태에 따라 색상/점선 애니메이션 트리거 필요. |
| **CTA 버튼** | 네온 시안의 반투명 배경을 가진 직사각형 형태. 텍스트는 '서사적 자산 업데이트'. | `:hover` 시, 내부에서 빛이 차오르는(Filling Glow) 인터랙션 적용. (클릭 가능 영역임을 암시). |

#### ✨ 버전 B: 럭셔리/서사 중심 (Luxe, Cinematic)
*   **감성:** 고대 기록의 발견, 귀족적인 소유권, 영화적 경험.
*   **톤앤매너:** 딥 네이비(Navy #1A237E), 골드(#FFD700), 크림 화이트.
*   **폰트:** Playfair Display (Serif, 클래식함) + Inter (보조 정보).
*   **Gap 표현:** 장식적인 프레임워크와 금박(Gold Foil) 질감을 사용한 '봉인된 서사' 느낌 강조.

| 요소 | 상세 디자인 규칙 | 개발 참고 사항 |
| :--- | :--- | :--- |
| **배경** | 딥 네이비 벨벳 텍스처 배경 (은은한 빛 반사 효과). | 전체 영역을 고전적인 '책의 페이지'처럼 보이게 프레임워크로 감싸는 애니메이션 필요. |
| **Gap 표시** | 불완전한 부분에 금빛으로 봉인된 듯한(Sealed Wax) 엠블럼이나, 빈 공간이 마치 비어있는 석판처럼 보이는 디자인 사용. | 'Missing Piece' 영역을 테두리(Border-Art)로 강조하고, 이 부분을 채워야 함을 스토리텔링 구조로 유도. |
| **CTA 버튼** | 골드 라인의 화려한 직사각형/타원형 형태. 텍스트는 '나의 서사를 완성하다'. | `:click` 시, 마치 무거운 금속 장치가 풀리며 빛이 새어 나오는(Unveiling) 애니메이션 적용. |

### ✨ 핵심 인터랙션 레퍼런스: '서사 업데이트 (Story Update)' 애니메이션
**목표:** 유료 결제 직후, 사용자가 얻게 된 자산의 가치를 가장 극적으로 체감하게 만드는 3단계 전환 애니메이션을 설계합니다.

| 단계 | 액션/트리거 | 시각적 효과 및 연출 | 개발 구현 원칙 (애니메이션) |
| :--- | :--- | :--- | :--- |
| **1. 결제 확인** | Paywall 성공 → 'Purchase Complete' 메시지 표시. | 전체 화면의 어두운 노이즈가 서서히 걷히며, 밝은 네온 시안/골드 빛이 새어 나옴. (Dramatic Reveal) | `Transition: opacity(0) -> opacity(1)` + 미세한 진동 효과 (`shake` CSS). |
| **2. 데이터 주입** | 시스템이 '서사적 업데이트'를 시작한다는 메시지 표시. | 사용자의 이름 모듈들이 원래의 자리에 있던 빈 공간으로 빛나는 아크와 함께 *강제적으로* 끌려 들어가며 제자리를 찾음. (Filling Arc) | `Keyframe Animation`: 요소들의 위치(Position: A -> B)가 서사적 연결선을 따라 부드럽게 이동하며, 도착 지점에서 '플래시' 효과 발생. |
| **3. 완성 자산 노출** | 업데이트 완료 메시지 및 최종 Mockup 컴포넌트 표시. | 가장 처음에 블러 처리되어 있던 핵심 정보(예: 깊은 기원 스토리) 부분이 선명하고 입체적인 3D 글리치 효과와 함께 나타남. | `Animation`: Opacity가 점진적으로 증가함과 동시에, 배경의 노이즈/블러가 제거되며 '선명한' 상태로 전환되는 시각적 보상 제공. |
