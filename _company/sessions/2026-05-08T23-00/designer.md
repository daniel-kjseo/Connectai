## 🛠️ 디자인 스펙 문서: 모듈형 정체성 시뮬레이터 (Modular Identity Simulator) UI/UX 정의
CEO 지시에 따라, 사용자가 이름 요소를 조합하는 과정을 단순한 데이터 입력이 아닌, '서사를 완성해가는 행위'로 느끼게 만드는 인터랙티브 와이어프레임 및 컴포넌트 가이드라인을 제시합니다.

### 📌 1. 페이지 레이아웃 개요 (Layout Structure)
| 영역 | 역할 | 구성 요소 | 상세 설명 |
| :--- | :--- | :--- | :--- |
| **A. 제어판 (Input/Control)** | 사용자 액션 유도 및 조합 관리 | 모듈 선택 드롭다운, 조합 미리보기 바, CTA | 사용자가 요소를 선택하고 '합성' 버튼을 누르는 주 인터랙션 영역. |
| **B. 메인 Mockup 뷰 (Live Preview)** | 핵심 시각적 자산 소유권 경험 제공 | 고화질 가상 결과물, 실시간 변화 애니메이션 | 조합된 이름/요소가 적용되는 최종 명함, 프로필 카드 등의 목업이 위치하는 곳. **가장 중요한 영역.** |
| **C. 서사 심화 가이드 (Narrative Deepening)** | '왜 이 요소가 중요한지' 설명 및 구매 동기 부여 | 모듈 분석 위젯, 연결 스토리라인, 다음 단계 CTA | 사용자가 조합한 각 요소를 기반으로 그 의미와 잠재력을 해석해주는 영역. 소유욕을 자극하는 핵심 지점. |

### 🎨 2. 핵심 컴포넌트별 디자인 스펙 (Component Specs)

#### **[A] 제어판: 모듈 선택 및 조합 관리**
*   **배치:** 페이지 최상단, 가로형 탭/슬라이더 방식 (Width: 100%)
*   **요소:**
    1.  **모듈 타입 Selector:** Prefix / Core Name / Suffix (선택 가능한 모듈 그룹을 보여줌)
    2.  **입력 필드:** 현재 조합된 요소 이름 표시 (`[Input Value]`)
    3.  **조합 미리보기 바 (Visual Feedback):** 선택한 요소들이 연결되는 시각적 라인과 함께 배치됨.
        *   *디자인 규칙:* 각 모듈 사이에는 **실선(Solid Line)**이 아닌, **흐릿하고 은은하게 빛나는 연결선(Glowing Connection Arc)**을 사용하여 '서사적 흐름'을 강조합니다. (색상: `#D0B3FF` - 연한 바이올렛)
    4.  **CTA:** `[✨ 서사 조합하기]` 버튼 (버튼 클릭 시, B와 C 영역에 애니메이션과 함께 결과가 반영됨).

#### **[B] 메인 Mockup 뷰: 실시간 변환 및 소유권 강조**
*   **기능:** 사용자가 A에서 모듈을 변경할 때마다 B의 목업이 즉각적으로 업데이트되어야 합니다. (지연 시간 최소화)
*   **디자인 목표:** 단순히 글자만 바뀌는 것이 아니라, '요소가 자리 잡는 경험'을 시뮬레이션해야 합니다.
*   **상태별 변화 로직 예시 (Example Flow):**
    1.  **(초기 상태 - 미조합):** 목업 전체가 옅은 회색(Grey Scale) 또는 워터마크 처리된 블러 효과가 걸려 있습니다. 핵심 정보만 노출되고, 나머지 부분에는 `[자산 완성 필요]`라는 문구가 배치됩니다.
    2.  **(결합 과정 - 조합 완료):** 사용자가 모듈을 조합하면, 해당 요소에 맞는 **'하이라이트 영역(Spotlight Area)'**이 Mockup 상에 생겨나며, 블러가 해제되고 선명한 색상과 폰트로 채워집니다.
    3.  **(프리미엄 강조):** 목업의 가장 중요한 부분 (예: 서사적 슬로건)은 항상 **'유료/Premium'** 표시와 함께 배치되어, 이 완성도를 위해 결제가 필요함을 시각적으로 주입합니다.

#### **[C] 서사 심화 가이드: 깊이 부여 및 구매 동기 극대화**
*   **목적:** 조합된 요소가 가진 '의미론적 가치'를 설명하며 사용자의 만족도와 소유 욕구를 동시에 높입니다. (구매 전환을 위한 가장 중요한 영역)
*   **구조:** 3개의 카드로 구성되며, 각 카드는 조합된 모듈 중 하나를 분석합니다.

| 위젯 이름 | 입력 데이터 기반 분석 내용 | 시각적 표현/애니메이션 | CTA 연계 |
| :--- | :--- | :--- | :--- |
| **1. 핵심 키워드 추출** | `Prefix`와 `Core Name`의 조합에서 파생된 3가지 강력한 키워드를 제시. (예: '지혜', '도전', '창조') | 키워드가 마치 빛을 내며 카드에 떠오르는 듯한 애니메이션 효과 적용. | "이 키워드들을 바탕으로 전문 슬로건 완성하기 (Premium)" 버튼 배치. |
| **2. 서사적 배경 해석** | 사용자가 입력한 이름을 기반으로 가상의 '탄생 배경'이나 '잠재력 스토리'를 짧은 문장(3~4줄)으로 작성. | 고전적인 텍스트 패널 느낌, 마치 비밀스러운 문서가 펼쳐지는 듯한 모션 적용. | "나만의 서사 기록물 영구 소유하기 (Premium)" 버튼 배치. |
| **3. 컬러 & 타이포 가이드** | 조합된 이름에 가장 잘 어울리는 브랜드 컬러 팔레트(Hex Code 3가지)와 권장 폰트를 제시. | 스와치(Swatch) 형태로 색상 코드가 명확히 표시되고, 폰트 미리보기를 통해 고급스러움을 강조. | "완벽한 브랜딩 패키지 받기 (Premium)" 버튼 배치. |
