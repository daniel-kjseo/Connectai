## 🖼️ [컴포넌트 이름] Arc Completion Gateway (AC-Gateway)
*   **목표:** 사용자가 자신이 완성한 모듈의 가치를 인지하고, 미완성된 부분(Gap)을 채워야 한다는 '소유 욕구'를 자극하여 유료 결제를 유도한다.
*   **적용 시점:** `useArcTracker`가 `$S_{critical}$` (예: 70 이상)에 도달하고 `isGapDetected: True`일 때, 기존 UI 위에 오버레이(Modal/Overlay Card) 형태로 나타난다.
*   **핵심 비주얼 요소:** 빛나는 아크 연결선(`Neon Cyan #00FFFF`)의 단절과 결핍.

### 🧪 A/B 테스트 변형 가능 요소 (Variables for Testing)
| 변수명 | 설명 | 테스트 목표 | 제안 값 (예시) |
| :--- | :--- | :--- | :--- |
| **A_Tone** | 메시지의 어조와 감성적 접근 방식. | 구매 동기의 원천 파악 (실용 vs 감정). | 1. 데이터 기반 (과학적 결핍), 2. 스토리텔링 기반 (감성적 완성) |
| **B_Metaphor** | Gap을 시각화하는 은유적 장치. | 어떤 비주얼이 가장 높은 전환율을 보이는지 측정. | 1. 단절된 빛의 아크, 2. 빈칸 채우기(Blank Slate), 3. 열쇠가 필요한 자물쇠 |
| **C_Urgency** | 결제를 미루거나 망설이는 사용자에게 주는 시간적 압박감. | 구매 결정 과정에서의 즉각적인 개입 필요성 검증. | 1. 없음 (평온함 유지), 2. 제한된 기회 강조 ("오늘만"), 3. 곧 사라질 것 같은 아우라 ("시간이 지나면...") |

### ✨ Version 1: 미니멀리스트/테크 기반 (Minimal & High-End)
*   **컨셉:** 사용자가 과학적이고 구조적인 결핍을 느끼게 합니다. 고가 기술 제품의 '최종 업그레이드' 느낌을 강조합니다.
*   **어울리는 톤:** 정밀함, 논리적 완성도, 전문가 지향.

#### 📐 UI/UX 가이드라인 및 레이아웃 (Desktop 기준)
1.  **배경:** 어두운 배경 (Deep Navy: `#0D1B2A`). 모듈 시뮬레이터의 깊은 공간감을 유지.
2.  **오버레이 카드 크기:** 와이드하고 긴 직사각형 형태 (예: 85% Width, 400px Height).
3.  **Gap Visualization (핵심):**
    *   사용자가 조합한 모듈 요소들이 빛의 아크로 연결되어 있다가, 특정 지점(Critical Gap)에서 **아크가 급격히 끊어지는 그래픽**을 배치합니다.
    *   끊어진 부분에는 투명한 격자 무늬와 함께 `[INCOMPLETE ARCS]` 텍스트를 네온 시안으로 삽입합니다. (좌표: 중앙, 상단).

#### 💬 컴포넌트 구성 요소 및 Copywriting
| 영역 | 디자인/애니메이션 | Copywriting 예시 | A/B 테스트 적용점 |
| :--- | :--- | :--- | :--- |
| **헤드라인** (H2) | 네온 시안 글씨, 미세하게 깜빡이는 애니메이션. | **[WARNING] 서사적 깊이 75% 도달. 아크 완성도가 임계점에 있습니다.** | A_Tone: [Warning] 대신 'Optimization Required' 사용. |
| **바디 메시지** (P) | 정렬된 데이터 리스트 형식으로 설명합니다. | 현재 모듈 조합만으로는 \[*추가 서사 구조*\], \[*소유권 인증 과정*\]의 일부를 완성할 수 없습니다. 이 결핍을 채워야 완벽한 자산이 됩니다. | B_Metaphor: 'Gap' 대신 'Missing Link Component' 명시. |
| **CTA 버튼** (Button) | 네온 시안 배경, 마우스를 올리면 빛나는 효과(Glow). | 🔓 **[Premium Unlock] 서사 아크 완성하기 (1회)** | C_Urgency: "지금 바로 잠금 해제" 등 즉각적인 문구 사용. |

### ✨ Version 2: 럭셔리/서사 기반 (Luxurious & Emotional)
*   **컨셉:** 사용자에게 '놓치고 있다'는 상실감(Loss Aversion)을 극대화합니다. 단순한 구매가 아닌, **자신의 정체성을 완성하는 행위**로 포지셔닝합니다.
*   **어울리는 톤:** 신비로움, 중요성, 개인적 성취감, 영화적인 드라마틱함.

#### 📐 UI/UX 가이드라인 및 레이아웃 (Desktop 기준)
1.  **배경:** 깊고 부드러운 그라데이션 배경 (Midnight Blue $\rightarrow$ Violet). 은은한 빛의 입자(Particle effect)가 떠다닙니다.
2.  **오버레이 카드 크기:** 비대칭적이고 유기적인 형태 (예: 모서리가 둥글고, 한쪽이 빛을 받는 듯한 곡선 처리).
3.  **Gap Visualization (핵심):**
    *   사용자가 만든 서사 아크 전체가 **반투명하게 배경에 그려져 있다가**, Gap 지점에서 갑자기 색이 바래거나 흐릿해지는(Desaturated) 효과를 줍니다.
    *   '미완성된 자산'이라는 느낌을 주기 위해, 빈 공간 주변으로 어두운 안개나 '잠재력의 실루엣' 같은 그래픽 모티프를 사용합니다.
